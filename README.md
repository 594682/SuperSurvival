Java 17 / Minecraft Forge 47.3.0 / Minecraft 1.20.1

## 编译
1. 安装 Java 17、Gradle 8.x（或使用 Forge MDK 的 Gradle Wrapper）。
2. 在项目根目录运行 `gradle build`。
3. 构建成功后，JAR 位于 `build/libs/`，放入游戏的 `mods` 文件夹。
4. 本项目提供源码，不包含已编译、已验证的 JAR。

## 功能
- 坐矿车：WASD 水平飞行，空格上升，Shift 下降；末影龙骑乘同样使用这些按键。
- 1 黑曜石 + 1 任意镐：无序合成传送门方块（当前合成会消耗镐）。
- 右键传送门方块：主世界 / 下界之间切换；在目的地出生点附近建立安全落脚点。
- 白天看向天空接近正上方、头顶露天时，手持空桶右键得到岩浆桶。
- 玩家攻击村民一次：转换成满级图书管理员，1 泥土换自定义物品。
- 首次进入主世界：在世界出生点附近建造四间简易木屋，生成 8 个村民。
- 手持末地烛攻击末影龙：尝试骑乘并发送飞行控制。
- 作者标注“此由生成”，模组信息官网地址为指定 Bilibili 链接。

## 重要的 1.20.1 兼容性差异
- 1.20.1 **没有重锤（mace）和风爆（wind_burst）**，相应交易暂以合金锄代替。
- 1.20.1 附魔名为 `sweeping`，不是 `sweeping_edge`。
- 1.20.1 使用物品 NBT 而不是 1.21+ 组件；附魔 255 采用 NBT 方式写入。
- 1.20.1 常规物品堆叠上限无法仅靠物品 NBT 改成 99。67 个物品的交易可能被客户端或容器限制，实际表现依赖原版逻辑。
- 当前“村庄”为出生点附近自动建造的简易聚落，并非原版结构生成系统生成的完整村庄。
- 末影龙为特殊多部件 Boss，原版不保证可正常骑乘；此功能仍需要在游戏中测试并进一步适配。
- Shift 在原版默认用于下车，可能与下降操作冲突，需要修改游戏下车按键。
- 飞行矿车目前仅在客户端发送控制时持续设置速度，停止输入后原版矿车物理可能影响悬停。
- 此项目尚未在本环境实际执行 Forge Gradle 编译，不能保证零编译错误。

## v2 新功能
- 模组列表图标使用用户提供的「群主」头像（logo.png）。
- 第一次登录主世界时自动设置世界 `keepInventory=true`，保留背包和经验；该规则作用于整个世界。
- 游戏内连续按三次 L（相邻按键间隔不超过 1.5 秒），在**单人游戏且为世界所有者**时赋予管理员命令权限；极限模式也不切换游戏模式。
- 为防止服务器权限被滥用，联机服务器上的 LLL 不会授予 OP 权限。
- 此功能不会解除极限模式死亡后的旁观者/存档限制，也不会自动复活。
